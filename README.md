# SQL Server Interview Playbook: 51 Questions, Fresher to 5+ Years

A free 143-page PDF booklet for anyone preparing for a SQL Server (T-SQL) interview.
By **Deepankar Sir**, MarutiNovaTech.

[Download the PDF](./SQL-Server-Interview-Playbook-51-Questions.pdf)

## What is inside

- **51 questions** in 4 levels: Fresher (13), Junior to Mid 1-3 years (14),
  Mid to Senior 3-5 years (14), Senior 5+ years (10)
- **Tags** on every question: MOST ASKED, IMPORTANT, LOGICAL, VARIANT FAMILY
- **Chance of being asked** for each question (our estimate, see note below)
- **All the ways to solve it.** Each way has "why use it" and "when it fails".
  Example: second highest salary with DENSE_RANK, ROW_NUMBER, RANK, MAX subquery,
  OFFSET FETCH, TOP twice and a correlated subquery
- **Execution order** boxes that show how SQL Server runs the query, step by step
- **About 47 diagrams**: join Venns, tables, timelines, execution plans
- **The interviewer's trap** and the follow-up questions hiding inside each one
- A practice script to build the tables and run every query yourself
- A last-night revision sheet with the 24 highest-probability questions

## How to use it

1. Run the setup script (page 4) in SSMS or Azure Data Studio.
2. Start with the questions tagged MOST ASKED.
3. Read "Say this first" and practise saying it out loud.
4. Run every query and compare your output with the book.

## Who is it for

Students and job seekers for Data Analyst, SQL Developer, BI Developer and
Data Engineer roles using Microsoft SQL Server.

## Note

All code is T-SQL for Microsoft SQL Server. Where a feature needs a newer
version, the page says so. The percentages are estimates based on interview
lists, guides and videos, not measured statistics.
